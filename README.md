Фанатский разбор: прогноз сюжета шестой главы DELTARUNE по декомпилированному коду глав 1–5.
Сценарий главы, 33 ставки, тайные маршруты (Странный путь и Маршрут меча) и находки в коде.

Читать: откройте `index.html` (это и есть вся страница, один файл со всеми картинками внутри).
